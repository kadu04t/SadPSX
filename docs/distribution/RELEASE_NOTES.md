# SadPSX 0.0.2 Beta 1

This beta replaces the basic file picker with a console-style SDL3 dashboard.
It adds a game library, covers, themes, persistent settings, controller
remapping, play history, boot animation, and navigation designed for fullscreen
use.

The emulation core also gains analog controllers, persistent memory cards,
expanded GTE precision, improved GPU/DMA ordering and arbitration, central
timing events, more precise MDEC decoding, XA audio paths, and substantially
better diagnostics. Rayman and Silent Hill reach playable gameplay; Final
Fantasy VII reaches gameplay and battles.

This is still experimental software. Audio remains inaccurate, software
rasterization has visible defects, performance may fall below real time, and
many games are untested.

No BIOS or game files are included. Use only legally obtained dumps from
hardware and media you own.
