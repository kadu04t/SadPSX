# SadPSX 0.0.1 Beta 1

This is the first public beta of SadPSX, an experimental PlayStation emulator
focused on hardware fidelity, diagnostics, and a maintainable C#/.NET core.

The release can boot the SCPH-1001 BIOS, load BIN/CUE disc images, recognize
SDL3 gamepads, and run Rayman into playable gameplay. It also includes a small
launcher for selecting a BIOS and disc image without using the command line.

Graphics, audio, timing, and game compatibility are still incomplete. Expect
visual corruption, audio issues, hangs, and games that do not boot.

No BIOS or game files are included. Use only legally obtained dumps from
hardware and media you own.
